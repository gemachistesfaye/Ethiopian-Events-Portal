# Ethiopian Heritage Intelligence Portal — Project Overview

## What is it?

The **Ethiopian Heritage Intelligence Portal** is a premium, full-featured cultural web application built to preserve, celebrate, and explore Ethiopian history, traditions, and events. It serves as a bridge between Ethiopia's ancient past and modern technology, offering users an immersive, AI-powered journey into one of the world's oldest civilizations.

## Vision

To create the most comprehensive, beautifully designed, and technically sophisticated digital resource for Ethiopian cultural heritage — freely accessible to anyone, anywhere in the world.

## Core Pillars

| Pillar | Description |
|---|---|
| 🗓️ **Dual Calendar** | Precise Gregorian ↔ Ethiopian calendar synchronization |
| 🗺️ **Interactive Atlas** | Real geographic map with clickable regions & cultural profiles |
| 🤖 **AI Heritage Guide** | Gemini-powered conversational storyteller & historian |
| 📜 **Historical Timeline** | Chronological archive of Ethiopia's most pivotal events |
| 🎉 **Culture Zone** | Trivia, food, music, and cultural exploration hub |
| 🔐 **Secure Auth** | Supabase-powered user authentication & profile management |

## Target Audience

- Students and researchers interested in Ethiopian culture
- Ethiopian diaspora seeking connection to their heritage
- Tourists and travelers planning cultural visits to Ethiopia
- Educators teaching African and world history

## Tech Philosophy

This project was engineered with a **performance-first**, **mobile-ready** mindset. Every component was built as a focused, reusable React module. The AI integration uses fallback offline registries to ensure the app never breaks, even under poor connectivity.
